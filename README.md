# 🚀 Tính Năng Nổi Bật

## 🔥 Đa Luồng Multi-Login

Điều khiển đồng thời hàng chục tab **LDPlayer** mà không bị chéo luồng.
Hỗ trợ nhập danh sách **Tài khoản / Mật khẩu** cực nhanh từ **Text**
hoặc **Excel**.

## 👁️ Mắt Thần Nhận Diện (AI)

Ứng dụng **OpenCV** để nhận diện hình ảnh với chế độ **Check Ảnh 60s**.
Tự động xử lý khi mạng lag hoặc hình ảnh chưa xuất hiện: chờ, kiểm tra
lại hoặc dừng an toàn, tránh thao tác sai.

## ⚙️ Tùy Biến Kịch Bản (Macro)

Tự do xây dựng quy trình tự động với các thao tác: - Click theo tọa độ
(lấy điểm trực tiếp) - Tự động nhập Tài khoản / Mật khẩu - Lặp vòng
(Loop) - Chạy nối tiếp nhiều Script

## 🔐 Bảo Mật 8 Lớp Khép Kín

Tích hợp cơ chế khóa phần cứng **HWID** cùng giao thức mã hóa **Reverse
Base64** giúp tăng cường bảo vệ dữ liệu và hạn chế việc phân tích, can
thiệp hoặc bắt gói tin.

## 📱 Kiểm Soát Ứng Dụng

Điều khiển trực tiếp hệ thống Android: - Mở ứng dụng bằng **Package
Name** - Xóa Data App để làm sạch cache - Cài đặt hàng loạt file APK

## 🤖 Tự Động Cài Đặt (Auto ADB)

Tự động nhận diện môi trường. Nếu máy chưa có **ADB**, phần mềm sẽ tự
tải xuống, giải nén và cấu hình **Path** chỉ với một thao tác.
